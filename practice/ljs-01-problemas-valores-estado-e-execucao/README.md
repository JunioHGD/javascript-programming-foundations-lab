# LJS-01 — Problemas, valores, estado e execução

[JavaScript & Programming Foundations Lab](../../README.md) › [Prática](../README.md) › LJS-01

Este bloco estabelece o modelo inicial de programa, conectando problemas, dados, expressões e alterações de estado antes da introdução de estruturas de controle mais complexas.

## Objetivo

Construir o primeiro modelo mental de programa: representar um problema como dados e operações cuja execução transforma estado de maneira previsível.

### [LJS-01.03 — Expressões e transformação de valores](./ljs-01.03-expressoes-e-transformacao-de-valores/)

Raciocinar sobre como expressões produzem resultados e transformam dados.
