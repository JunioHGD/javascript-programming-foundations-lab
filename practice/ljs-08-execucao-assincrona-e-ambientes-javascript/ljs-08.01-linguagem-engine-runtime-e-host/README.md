# LJS-08.01 — Linguagem, engine, runtime e host

[JavaScript & Programming Foundations Lab](../../../README.md) › [Prática](../../README.md) › [LJS-08 — Execução assíncrona e ambientes JavaScript](../README.md) › LJS-08.01

A unidade separa as responsabilidades de ECMAScript, engine, runtime e host para evitar atribuir à linguagem mecanismos fornecidos pelo ambiente.

[![Verificação de conhecimento](https://img.shields.io/badge/Verifica%C3%A7%C3%A3o_de_conhecimento-Abrir-2563EB?style=flat-square)](./knowledge-check.md) [![Evidências práticas](https://img.shields.io/badge/Evid%C3%AAncias_pr%C3%A1ticas-Abrir-16A34A?style=flat-square)](./exercicios/)

## Objetivo

Estabelecer corretamente as responsabilidades das diferentes camadas.

## Conceitos fundamentais

1. ECMAScript como especificação da linguagem;
2. engine como implementação da linguagem;
3. runtime e ambiente hospedeiro;
4. APIs fornecidas pelo host;
5. execução síncrona e call stack;
6. operações externas ao fluxo síncrono;
7. jobs ECMAScript;
8. event loop como mecanismo do ambiente;
9. diferença conceitual entre browser e Node.js.

## Síntese

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre conceitos e resultados que se mostrarem essenciais para compreender **Linguagem, engine, runtime e host**.
