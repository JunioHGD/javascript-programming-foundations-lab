## Objetivo

Conhecer apenas a camada necessária para prever a ordem básica do código assíncrono.

## Conceitos fundamentais

1. trabalho síncrono até a conclusão;
2. Promise reactions como jobs;
3. microtasks no modelo do host Web;
4. tasks versus microtasks no navegador;
5. checkpoints de microtasks;
6. relação conceitual entre Promise e fila de microtasks;
7. diferenças de runtime;
8. timers como APIs do host, não da linguagem.

## Síntese

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre conceitos e resultados que se mostrarem essenciais para compreender **Jobs, tasks e microtasks**.
