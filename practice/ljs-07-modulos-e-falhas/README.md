# LJS-07 — Módulos e falhas

[JavaScript & Programming Foundations Lab](../../README.md) › [Prática](../README.md) › LJS-07

Este bloco introduz modularização e tratamento de falhas, tornando explícitas as dependências entre unidades de código e a propagação de erros.

## Objetivo

Passar de programas monolíticos para unidades com dependências explícitas e desenvolver um modelo fundamental de falhas e propagação.

## Unidades

### [LJS-07.01 — Módulos ECMAScript](./ljs-07.01-modulos-ecmascript/)

Organizar código por responsabilidades sem confundir sintaxe da linguagem com carregamento do ambiente.

### [LJS-07.02 — Erros e exceções](./ljs-07.02-erros-e-excecoes/)

Distinguir diferentes classes de falha e controlar erros recuperáveis.
