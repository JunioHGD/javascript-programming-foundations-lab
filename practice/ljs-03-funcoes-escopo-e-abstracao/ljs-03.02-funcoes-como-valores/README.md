## Objetivo

Compreender a característica de primeira classe das funções em JavaScript.

## Conceitos fundamentais

1. função como valor;
2. referências a funções;
3. function declarations e function expressions;
4. arrow functions;
5. callbacks;
6. funções recebendo funções;
7. funções retornando funções;
8. funções de ordem superior.

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre conceitos e resultados que se mostrarem essenciais para compreender **Funções como valores**.
