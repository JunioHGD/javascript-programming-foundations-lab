# Projetos

Esta seção reunirá projetos de integração ampla do **JavaScript & Programming Foundations Lab**. Diferentemente dos checkpoints, que consolidam um bloco específico, os projetos daqui podem combinar conhecimentos desenvolvidos em múltiplos blocos do currículo quando essa integração produzir uma evidência técnica relevante.

Cada projeto publicado terá pasta e `README.md` próprios, com apresentação do problema, objetivos, competências integradas, implementação e decisões técnicas pertinentes ao trabalho realizado.
