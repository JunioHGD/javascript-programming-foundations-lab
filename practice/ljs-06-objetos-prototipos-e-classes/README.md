# LJS-06 — Objetos, protótipos e classes

[JavaScript & Programming Foundations Lab](../../README.md) › [Prática](../README.md) › LJS-06

Este bloco constrói o modelo de objetos do JavaScript a partir de propriedades e protótipos, avançando para `this`, construção e classes sem separar essas ideias do sistema prototípico.

## Objetivo

Construir o modelo de objetos específico do JavaScript antes de introduzir classes, evitando tratá-las como um sistema independente de orientação a objetos.

## Unidades

### [LJS-06.01 — Propriedades e cadeia de protótipos](./ljs-06.01-propriedades-e-cadeia-de-prototipos/)

Compreender como propriedades são localizadas e comportamentos podem ser compartilhados.

### [LJS-06.02 — Métodos, `this` e construção](./ljs-06.02-metodos-this-e-construcao/)

Compreender como a forma de chamada influencia o contexto de uma função.

### [LJS-06.03 — Classes sobre o modelo prototípico](./ljs-06.03-classes-sobre-o-modelo-prototipico/)

Usar a sintaxe de classes mantendo explícita sua relação com o sistema de objetos da linguagem.
