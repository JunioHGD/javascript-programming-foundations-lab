## Objetivo

Usar a sintaxe de classes mantendo explícita sua relação com o sistema de objetos da linguagem.

## Conceitos fundamentais

1. classe como mecanismo de definição de objetos;
2. constructor;
3. criação de instâncias;
4. métodos de instância;
5. relação entre classe, instância e protótipo;
6. `this` em métodos e construtores.

## Síntese

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre conceitos e resultados que se mostrarem essenciais para compreender **Classes sobre o modelo prototípico**.
