# Web Integration

Este diretório reunirá as atividades de **Web Integration** do Lab.

Cada atividade aplicará os fundamentos de uma unidade em uma situação Web funcional, integrando **HTML, CSS e JavaScript** quando pertinente, sem perder o foco da tecnologia principal estudada.

As atividades serão organizadas progressivamente por unidade e adicionadas conforme o avanço do Lab.
